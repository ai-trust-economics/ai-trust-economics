# Code of Conduct

We want rigorous disagreement without personal hostility.

Participants should:

- criticize mechanisms, assumptions, evidence, and arguments rather than people;
- distinguish demonstrated failures from hypothetical failures;
- disclose relevant conflicts of interest when they materially affect a proposal;
- avoid harassment, threats, discrimination, or targeted abuse;
- treat good-faith adversarial analysis as a contribution rather than disloyalty;
- avoid publishing operational exploit details that create immediate material risk to real systems.

Maintainers may moderate contributions that violate these expectations.

# RFC Process

RFCs are the project's mechanism for substantial design proposals.

## Lifecycle

```text
Draft -> Proposed -> Experimental -> Accepted / Rejected / Superseded
```

Acceptance means the proposal is the current working design, not that it is proven safe.

## Required sections

Every RFC should include:

- status
- authors
- problem
- goals
- non-goals
- assumptions
- proposed mechanism
- security / abuse analysis
- collusion analysis
- governance / capture analysis
- false-positive / recovery analysis
- alternatives
- falsification / experiment plan
- open questions

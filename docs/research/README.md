# Research

This directory tracks adjacent standards, research programs, and empirical results relevant to AI Trust Economics.

The aim is not to claim the project is entirely novel. Many primitives already exist independently:

- workload and machine identity
- verifiable credentials
- remote attestation
- reputation systems
- Sybil resistance
- mechanism design
- AI control and monitoring
- Cooperative AI
- multi-agent security

The research question is whether these can be composed into a credible, adversarially robust infrastructure that ties persistent agent standing to enforceable capability access.
